Kubernetes Cheatsheets

Kubernetes corre contenedores en un grupo de máquinas y los mantiene funcionando: los reinicia si fallan, los escala y los actualiza sin cortes. Estas hojas lo explican desde cero (conviene saber lo básico de Docker antes) y usan como ejemplo una app Node llamada chanchito con su base MongoDB monguito.

Por dónde empezar

Si nunca usaste Kubernetes, seguí este orden.

  1. Empezar desde cero: activar el Kubernetes de Docker Desktop, correr tu primera app, escalarla y describirla en un archivo YAML.
  2. Conceptos: qué es un cluster, un Pod, un Deployment y un Service, y por qué Kubernetes trabaja con “estado deseado”.
  3. De Compose a K8s: llevar una app real al cluster, paso a paso, con todos los archivos.
  4. Manifiestos y Red, config y datos: entender cada parte de esos archivos.
  5. kubectl y Problemas comunes: para consultar cuando los necesites.

Ver y depurar

Ver los Podslistar, ps, estado
kubectl get pods -o wide
Ver todo lo del namespacelistar recursos, all
kubectl get all
Saber por qué falla un Poddescribe, eventos, error
kubectl describe pod <pod>
Ver logs en vivologs, follow, consola
kubectl logs -f deploy/chanchito
Logs del intento que crasheócrashloop, previous
kubectl logs <pod> --previous
Entrar al Podexec, shell, terminal
kubectl exec -it deploy/chanchito -- sh
Abrirlo desde mi PCport-forward, localhost, acceder
kubectl port-forward svc/chanchito 3000:80
Ver los eventos recientesevents, historial
kubectl get events --sort-by=.lastTimestamp

Desplegar y actualizar

Aplicar mis YAMLapply, desplegar, compose up
kubectl apply -f k8s/
Generar un YAML basedry-run, plantilla
kubectl create deployment x --image=x:1 --dry-run=client -o yaml
Escalar réplicasscale, más pods
kubectl scale deploy chanchito --replicas=3
Cambiar la imagenset image, nueva versión, update
kubectl set image deployment/chanchito chanchito=chanchito:2
Volver a la versión anteriorrollback, undo
kubectl rollout undo deploy/chanchito
Reiniciar los Podsrestart, recargar config
kubectl rollout restart deploy/chanchito
Borrar todo lo aplicadodelete, bajar, compose down
kubectl delete -f k8s/

Cluster y configuración

¿A qué cluster apunto?contexto, context
kubectl config current-context
Cambiar de clusteruse-context
kubectl config use-context docker-desktop
Cambiar namespace por defectonamespace, -n
kubectl config set-context --current --namespace=<ns>
Crear un Secretcontraseña, password
kubectl create secret generic mongo-secret --from-literal=KEY=valor
Usar mi imagen localminikube, kind, image load
minikube image load chanchito:1

Red y datos

¿El Service encuentra Pods?endpoints, selector, no responde
kubectl get endpoints chanchito
Probar DNS desde adentronslookup, busybox
kubectl run tmp --rm -it --image=busybox -- nslookup monguito
Conectar Compass a Mongomongo, base de datos
kubectl port-forward svc/monguito 27017:27017
Ver discospvc, volumen, storage
kubectl get pvc,pv
